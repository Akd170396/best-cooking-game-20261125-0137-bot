**Warung Rasa: Dapur Kilat** — a fast-paced original cooking game. You are the cook of a busy Indonesian warung: take orders from the board, grab ingredients from the bins, chop chicken and vegetables on the board, fry rice, noodles and eggs in two woks (before they burn!), assemble each dish on the plating counter, and serve it at the window before the ticket's timer runs out. Combos reward fast serving; the dinner rush in the last 45 seconds of the shift makes tickets arrive faster with shorter timers.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: the game is plain static files under `game/`. Move with WASD or arrow keys, act with E / Space / click, pause with P, mute with M. `MAKEFUN_OUTPUT_DIR=out node main.ts` hands the game in (copies `game/` and `screenshots/` to the output directory and writes `dossier.json`).
